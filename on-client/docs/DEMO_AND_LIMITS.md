# 헤임달 완성본 시연 순서, 한계와 근거 (총공세 7일차)

학생이 작성했습니다. 보안 Agent 「헤임달」 완성본을 처음부터 끝까지 보여 주는 순서와, 아직 안 되거나 「확인 불가」로 남은 한계, 그리고 실제로 확인한 근거를 나눠 적습니다. 확인하지 않은 것은 된다고 쓰지 않습니다. 이 문서는 학생의 실행·관찰 기록이며 ALEPH 판정이 아닙니다.

- 화면 틀: 관제 대시보드형(맨 위 상태 카드 네 개, 아래 추이와 기록)
- 포장 형태: 포장 없이 프로젝트 폴더에서 실행(`npm run package-app`은 실행하지 않음)
- 값 표시: **실측(학생 PC, 시각)** 은 학생 PC 화면에서 실제로 본 값이고, **예시 값(설명용)** 은 설명을 위한 값입니다. 예제 실행(`-Demo`)의 값은 「예제 자료(demo) · 실제 값 아님」입니다.

## 2. 시연 순서 (약 5분)

준비: `on-client` 폴더의 일반 PowerShell. 시연 전에 다른 창에서 켜 둔 앱은 끕니다.

| 순서 | 실행 | 누를 곳 | 보여 줄 것 |
|---|---|---|---|
| 0 | 기본 실행 | 브라우저 `http://127.0.0.1:5189/` | 화면 맨 위 「헤임달」, 보호 현황 첫 학생 칸의 「헤임달 핵심 기능 3가지」 |
| 1 | 기본 실행 | 「학생 상태·알림 표시」 → 「조회」, 10초 뒤 「다시 조회」 | **핵심 기능 ① 연결·상태 한눈에 보기**: 「SDP 서버 연결 · SDP 미연결(disconnected)」이 PC 조회 결과와 따로 보임. 카드 여섯 개에 값·`실측 · 이 PC · 시각`·단위, 「실측 6/6」, 추이 표의 직전 실측 대비. 작업 관리자 「성능」을 옆에 띄워 메모리 값 비교 |
| 2 | 기본 실행 | 「설치 패키지 조회」 | **핵심 기능 ② 설치 패키지 취약점 조회**: 「조회 준비 미완료(not_configured)」, 패키지 수·취약점 수 「조회 안 됨」. 0개·안전으로 보이지 않음 |
| 3 | 기본 실행 → 예제 실행 | 「보안 기록」 메뉴 | **핵심 기능 ③ 보안 기록·XDR 경보**: 기본 실행은 기록 요약 「조회 실패」(기록이 없다는 뜻이 아님). 앱을 끄고 `-Demo`로 다시 켜 목록·필터·「event-01 상세」를 보여 주며 「예제 자료(demo) · 실제 값 아님」을 짚음 |
| 4 | 기본 실행 | 앱 창에서 Ctrl+C → 브라우저 「다시 조회」 → 앱 다시 켜고 「다시 조회」 | 실패 화면: 「조회하지 못한 항목 · 여섯 항목 전체」와 다음에 할 일, 카드는 「확인 불가」. 다시 켜면 상자가 사라짐 |

말로 덧붙일 것: AI 연결은 포털에서 승인이 거부돼 아직 연결되지 않았고(원인 미확정), 화면이 그것을 연결 완료로 보이지 않게 표시한다는 점(3절).

## 3. 한계: 아직 안 되거나 「확인 불가」로 남은 것

| 항목 | 상태 | 이유 |
|---|---|---|
| AI 연결·AI 사건 설명 | **안 됨** | 계정 연결은 성공했지만 AI 앱 승인이 포털에서 "다른 프로젝트가 이미 등록돼 있어 진행하지 않았습니다"로 거부(확인 번호 a362-e9f8). 「AI 연결 점검」은 `ON_AI_PROVISIONING_PENDING`, 연결 요청은 `ALEKOV_CONNECT_EXPIRED`. 원인은 확정하지 못함. 수업용 AI 답(2026-10-29)으로도 학생이 할 조치는 확인되지 않았고, 포털 안내대로 과제 운영 SKT 담당자 확인이 필요함(아직 문의 전). 재현 폴더 시험은 보류. 「현재 API 연결 점검」(test/verified·모델 수)과 실제 사건 설명은 미확인 |
| 실제 로그인·기기·세션·보안 기록·업무 앱 판정 | **기본 실행에서 조회 실패** | 운영자 SDP 연결 설정이 없어 `ENGINE_NOT_CONNECTED`. 화면은 예제 실행으로만 확인 |
| 보안 조치 실행·결과 확인 | **안 됨** | 조치를 처리하는 연결이 없음 |
| 실제 OSV 취약점 결과 | **확인 불가** | 조회 대상 프로젝트가 설정되지 않음(`not_configured`). complete·partial 표시는 모의 점검만 |
| 권한 없음·오래된 값 표시(내 PC) | **모의 점검만** | 학생 PC에서 일반 권한으로 모든 항목이 읽혀 실제로 나타나지 않음 |
| AI 오류 원인별 문구, 「AI 연결 점검 취소」의 「취소됨」 | **모의 점검만** | 실제로는 응답이 즉시 와서 취소할 틈이 없었음 |
| 포장·바로가기 | **하지 않음** | 작전상 포장 없이 실행. `package-app` 미실행 |
| macOS·Linux 실행 | **미확인** | 학생 PC는 Windows. 수업용 AI의 Linux 작업 환경 결과는 보조 시험일 뿐 |
| 다른 사람의 실행 | **일부 확인** | 친구가 실행 안내 한 장만 보고 실행해 문제 없었다는 학생 진술만 있음(친구 PC 환경 미기록) |
| 시작 틀 0.2.21 갱신 뒤 새 폴더 재현 | **일부 확인** | 22단계 재현 기록은 0.2.14 때 커밋 `0a25836` 기준. 0.2.21 뒤에는 학생·친구가 실행 안내로 다시 따라 한 진술만 있음 |

### 4-3. 보조 시험·모의 점검(학생 PC 결과 아님)

## 5. 다시 하는 법

```powershell
# 저장소 폴더: 최신 받기와 제출할 커밋 번호
git pull origin main
git --no-pager status          # nothing to commit, working tree clean
git rev-parse HEAD             # GitHub 저장소 화면의 최근 커밋과 같아야 함

# on-client 폴더: 기본 실행(시연 0·1·2·4, 3의 앞부분)
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1

# on-client 폴더: 예제 실행(시연 3의 뒷부분), 기본 실행을 Ctrl+C로 끈 뒤
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Demo
```
