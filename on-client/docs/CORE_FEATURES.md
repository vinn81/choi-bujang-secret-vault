|---|---|

### 화면 표시 규칙

| 경우 | 표시 |
|---|---|
| 실제로 잰 값 | `실측 · 이 PC · HH:MM:SS`(잰 시각)와 단위. CPU는 %(200ms 표본), 메모리는 사용/전체 GB, 디스크는 여유/전체 GB. GB는 제공 카드와 같은 1024³ 바이트 기준 |
| 항목 하나를 읽지 못함 | 그 항목만 「확인 불가 · 이유: 읽기 권한 없음(permission_denied)」 등. 그 항목은 비교 불가 |
| 잰 시각이 받은 시각과 60초 넘게 다름 | 「확인 불가(오래된 값)」, 비교하지 않음 |
| 조회 실패 | 「조회 실패 (code)」, 잰 시각 없음, 이전 값을 현재 값처럼 쓰지 않음 |
| 학생 계약에 경로가 없는 앱 판 | 「지원 없음(NOT_ALLOWED)」, 제공 카드를 안내 |
| 예시 값(설명용) | 화면에 넣지 않음. 이 문서에도 예시 값은 없음 |

자동으로 다시 읽지 않으며, 기록은 브라우저 메모리에만 있어 새로고침하면 사라집니다. 파일·서버·AI로 보내지 않습니다. 예제 모드(`-Demo`)에서도 이 칸의 값은 이 PC 실측입니다.

### 다시 확인하는 순서 (학생 PC, PowerShell, `on-client` 폴더)

1. `git log --oneline -1`로 이 기능이 들어간 커밋인지 확인합니다.
2. `npm.cmd run check` → 오류 없이 끝나야 합니다.
3. `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1`로 켜고 브라우저에서 `http://127.0.0.1:5189/`를 엽니다.
4. 보호 현황 → 「학생 상태·알림 표시」 칸의 「내 PC 측정 추이 비교」에서 「내 PC 측정 기록 추가」를 누릅니다. 카드 세 개에 값·`실측 · 이 PC · 잰 시각`·단위가 나와야 합니다.
5. 10초쯤 뒤 한 번 더 누릅니다. 표가 2줄이 되고 맨 위 줄에 「직전 실측 … 대비」 차이가 나와야 합니다.
6. 같은 화면의 제공 「내 PC 상태」에서 「내 PC 확인」을 눌러 값의 크기가 비슷한지 비교합니다(잰 시각이 달라 CPU는 다를 수 있음).
7. 서버 창에서 Ctrl+C로 끈 뒤 버튼을 누릅니다. 「조회 실패」가 나오고 이전 값이 현재 값처럼 보이지 않아야 합니다.
8. 브라우저를 새로고침하면 기록이 사라지고 「아직 측정하지 않음」으로 돌아가야 합니다.

|---|---|---|
