학생이 작성했습니다. 22단계까지 만든 원래 작업 폴더에서 앱을 다시 실행하고, 권장 제작 기간에 다듬을 핵심 기능 3가지와 지금 되는지·안 되는지를 한 장에 정리합니다. 이 표는 학생의 실행·관찰이며 ALEPH 판정이 아닙니다.

|---|---|

| 주소 | `http://127.0.0.1:5189/` |
| 작전 | 화면 틀 관제 대시보드형(상태 카드 네 개 + 추이·기록), 포장 형태 기본 포장(포장 명령은 시작 틀 0.2.14에 아직 없음) |
| 확인 날짜 | 2026-10-27, 학생 PC(Windows, Node v24.21.0, Chrome) |

## 기능 점검표

| 다듬을 순서 | 핵심 기능 | 화면 위치 | 지금 상태 | 근거(학생 PC 실제 화면) | 안 되는 부분과 이유 |
|---|---|---|---|---|---|
| 1 | 연결·상태 한눈에 보기 (상태 카드 연결·기기·세션·알림 + 추이 표) | 보호 현황 → 「학생 상태·알림 표시」 | **지금 됨** — 연결 없음 결과를 실측으로 표시 | 16:02:50 카드 네 개 가로 배치, 16:14:26 추이 4줄(실측 3줄·예제 1줄 구분) | 실제 사용자·기기·세션 값: 운영자 SDP 연결 설정 필요 |
| 2 | 설치 패키지 취약점 조회 (조회 요약 카드) | 보호 현황 → 「학생 패키지 조회 표시」 | **지금 됨** — 결과는 조회 준비 미완료(not_configured) | 16:07:10, 16:14:46 not_configured, 패키지 수·취약점 수 "조회 안 됨" | 실제 OSV 결과와 패키지 행: 운영자의 조회 대상 프로젝트·허용 패키지 필요(complete·partial은 모의 점검만) |
| 3 | 보안 기록·XDR 경보 (기록 요약 카드 + 최신순 목록) | 보안 기록 → 학생 기록 칸 | **예제 모드에서만 됨** — 기본 실행은 조회 실패 | 16:11:46 기본 실행 네 카드 "조회 실패", 16:12:30 예제 1건·XDR 0건·거부 1건 | 실제 기록·경보: 운영자 SDP 연결 설정 필요 |

다듬을 순서: 연결·상태 한눈에 보기 → 설치 패키지 취약점 조회 → 보안 기록·XDR 경보

## 그 밖의 기능 (이번에 고르지 않음)

| 기능 | 지금 상태 | 이유 |
|---|---|---|
| 업무 앱 접근 판정 | 예제 모드에서만 됨 | SDP 연결 설정 필요 |
| AI 연결 점검 | 버튼은 됨, 결과는 권한 준비 중 | 학생 앱 AI 권한 준비 중(운영자) |
| AI 사건 설명 | 아직 안 됨 | 학생 앱 AI 권한 준비 중(운영자) |
| 보안 조치 실행·결과 확인 | 아직 안 됨 | 조치를 처리하는 연결이 준비되지 않음 |
| 기본 포장과 바로가기 | 아직 안 됨 | `npm run package-app` 명령이 시작 틀 0.2.14에 없음 |
| 내 PC 상태(CPU 사용률·메모리 사용량·디스크 남은 공간) — 총공세 2일차 | **아직 안 됨** · 화면에는 "확인 불가"와 이유만 표시(학생이 만든 자리) | 시작 틀 0.2.14에 제공 기능이 없음. 서버·`public/app.js`를 고치지 않고는 값을 읽을 경로가 없어(CSP `connect-src 'self'`) 담당자에게 제공 여부 문의 필요. 제공되면 그 값으로 바꾸고 추이 비교를 더할 예정 |

## 값 종류 구분

| 표시 | 뜻 |
|---|---|
| `실측 · 이 PC · HH:MM:SS` | 이 PC의 앱이 그 시각에 받은 결과. 조회 실패도 실측 결과 |
| `예제 자료(demo) · 실제 값 아님` | `-Demo` 예제 엔진의 값 |
| `아직 값 없음` | 응답이 끝나기 전 |
| 예시 값(설명용) | 설명 문서에서만 쓰며 화면에는 넣지 않음. 이 점검표의 값은 모두 위 실측·예제 결과에서 옮긴 것이고 예시 값은 없음 |

연결 없음·조회 실패·미조회는 0건이나 정상이 아닙니다. 다시 확인하는 순서는 [STUDENT_RUNBOOK.md](STUDENT_RUNBOOK.md) 5-1~5-3절에 있습니다.
