## 6. 이동 가능한 구성과 설정 견본

- 실행에 필요한 파일은 모두 저장소 안의 `on-client/`에 있으며, 문서와 명령은 상대 경로(`.\tools\start-alekov.ps1`, `.\on-client`)만 씁니다. 로컬 절대 경로나 비밀값에 의존하지 않습니다.
- 계정 연결 설정은 실행 도구가 `%USERPROFILE%\.aleph-keshev-<프로젝트 경로 해시>\native.json`에 프로젝트 경로마다 따로 준비합니다(원문 확인: `tools/start-alekov.ps1`). 새 폴더에서는 새 설정이 자동으로 만들어지므로 원래 폴더의 설정을 복사하지 않습니다(4절 4번에서 확인).
- 제공 `on-client/README.md`는 ".env.example에는 비밀 없는 설정만 있습니다"라고 적습니다. 시작 틀의 `on-client/.env.example`은 학생 PC의 원래 작업 폴더에 있지만, 저장소 최상위 `.gitignore`의 `.env.*` 규칙(4번째 줄)에 걸려 Git에 올라가지 않았고 제출 커밋에도 없습니다(학생 확인: `git check-ignore -v on-client/.env.example` → `.gitignore:4:.env.*`, `git ls-files on-client/.env.example` → 출력 없음). 내용을 검토하지 않은 파일은 제출에 넣지 않았으며, 아래 표를 설정 견본으로 씁니다. 값은 적지 않습니다.

| 설정 | 넣는 방법 | 담당 | 없을 때 |
|---|---|---|---|
| 포트 `ON_PORT` | 실행 도구 `-Port`가 설정(기본 5189) | 학생 | 5189 사용 |
| 예제 모드 | 실행 도구 `-Demo` | 학생 | 기본 실행(연결 없음) |
| SDP 연결 설정 파일 | 실행 도구 `-SdpHostConfig "<안내받은 절대 경로>"`. 파일은 프로젝트·Git 밖에 보관 | 운영자 발급 | 「연결 없음」(`ENGINE_NOT_CONNECTED`) |
| 계정 연결 설정 | 실행 도구가 자동 준비, 또는 `-NativeHostConfig` | 실행 도구 / 운영자 | `NATIVE_HOST_DISABLED` 등 |
| 조회 대상 프로젝트 `ON_PROJECT_DIRECTORY` | 서버 환경변수 | 운영자 | not_configured(`PROJECT_NOT_CONFIGURED`) |
| 허용 공개 패키지 `ON_APPROVED_PUBLIC_PACKAGES` | 서버 환경변수(JSON 배열) | 운영자 | not_checked(`NO_APPROVED_PACKAGES`) |
| 앱 전용 AI 자격 | 서버 쪽 보관. 실행 도구는 `ON_AI_`로 시작하거나 TOKEN·SECRET·API_KEY 등이 든 환경변수를 서버에 넘기지 않음 | 운영자 | 권한 준비 중(`ON_AI_PROVISIONING_PENDING`) |

키·토큰·비밀번호는 `.env`처럼 Git에서 빠지는 파일(저장소 `.gitignore`가 `.env`, `.env.*`를 제외)이나 운영자가 안내한 프로젝트 밖 경로에만 두며, 이 문서와 커밋에 적지 않습니다.

이 문서를 추가한 최종 커밋에서 학생이 확인할 내용입니다. 결과는 제출 화면의 설명란에 적습니다. 이 문서는 그 커밋 안에 들어가므로 자기 해시를 적을 수 없습니다.

```powershell
git diff --stat 0a258365c37075c4176312fdaa629c2643607298 HEAD
```

바뀐 파일이 문서 세 개(`README.md`, `on-client/docs/RELEASE_RECORD.md`, `on-client/docs/STUDENT_RUNBOOK.md`)뿐이면 4~5절의 재현 결과가 최종 커밋의 코드와 같은 코드에서 나온 것입니다. 코드 파일이 함께 바뀌었다면 이 재현 기록은 최종 커밋의 결과가 아니며 다시 재현해야 합니다.

## 9. 지원 범위, 누락·미해결 사항

지원하는 범위
- Windows PowerShell 실행 도구, Node.js 22~24(학생 PC 확인 v24.21.0), PC 브라우저(Chrome 확인), `127.0.0.1` 로컬 실행.
- 연결 없음·예제(demo)·권한 준비 중·미조회 상태를 성공과 구분해 표시하는 학생 화면.

미해결·미완료(검증 중 버전인 이유)
- 실제 접근 제어·XDR 시스템(SDP host) 연결: 운영자 SDP 설정 미발급.
- 계정 연결 승인과 AI 앱 승인, 「현재 API 연결 점검」 ok, 실제 AI 사건 설명과 근거 ID 대조: 학생 앱 권한 준비 중.
- 보안 조치 실집행(19단계)과 같은 학생·프로젝트·대상의 실행 결과 확인: 조치를 실제로 처리하는 연결이 준비되지 않음. 실제 학생 계정의 조치 결과는 기다림(UNV).
- 실제 OSV 조회와 package-lock.json 버전 대조: 조회 대상 프로젝트·허용 패키지 미설정.
- 설명·패키지 조회의 늦은 응답 차단과 오류 뒤 복구를 실제 화면에서 만들지 못함(원문 확인으로만 제공 코드의 세대 확인을 봄).
- 제공 README가 언급한 `.env.example`은 `.gitignore`의 `.env.*` 규칙 때문에 제출 커밋에 없음(6절). 다른 환경에서는 6절 표로 설정을 확인함.
- macOS·Linux에서의 실행 도구 실행, `-Port`·`-Background`·`-SdpHostConfig` 옵션 실행.
